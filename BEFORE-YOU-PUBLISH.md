# ERS–WVSU public-launch checklist

- [ ] Confirm the initiative's approved title, organizing structure, and relationship to WVSU.
- [ ] Obtain university approval for logo, font use, and relevant branding. The original text-based E.R.S. lockup is provisional.
- [ ] Read `EDITORIAL-AND-RESEARCH-SCOPE.md` and verify every claim about the initiative's current capacity and partnerships.
- [ ] Make sure no **specific unannounced research concept**, identification strategy, grant plan, or private draft is in the public repository or its history.
- [ ] Verify the organizer profile, academic title, professional link, and any photographs.
- [ ] Ask Dr. Frehot Hailou and Dr. Saman Bandara to review their public profiles before official launch; check that their ERS role labels are accurate.
- [ ] Verify the past-presenter list (Sossou Adjisse and Frehot Hailou) and confirm seminar dates/titles before posting event details.
- [ ] Obtain appropriate student consent before publishing project details, images, names, or work.
- [ ] Add only confirmed future seminars; confirm speakers' permission and public event information.
- [ ] Test the default email-draft form end to end. Its button opens the visitor’s email application but does not send the message automatically.
- [ ] If automatic responses are preferred, create and publish your own Google Form; insert the responder URL in Site settings and configure Google Forms notifications.
- [ ] Confirm author and speaker permission for each archived resource.
- [ ] Make sure no statement implies ERS–WVSU has an approved role in the new Agriculture Complex or other funded project.
- [ ] Consider WVSU institutional ownership or shared administration for continuity beyond any individual organizer.
- [ ] Review desktop and phone layouts, keyboard navigation, and readability. Use `content/appearance.json` to change sizes or colors.
- [ ] Run `python3 scripts/build.py` and `python3 scripts/check_site.py` and inspect the GitHub Actions result after pushing.
- [ ] Buy the domain **only after** selecting the name and confirming availability, price, ownership, and any branding approval.
